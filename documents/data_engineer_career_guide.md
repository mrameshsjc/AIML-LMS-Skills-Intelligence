# Career Guide: Becoming a Data Engineer

*Sample document for the LMS Skills Intelligence Engine. Fictional content for demonstration only.*

## What a Data Engineer does

Data Engineers build and run the pipelines that move data from source systems into analytics platforms. They design data models, write transformation code, automate jobs in the cloud and make sure data is reliable, documented and secure.

## Skills the role needs

The Data Engineer role requires Python at level 4, SQL at level 4, AWS at level 3, Machine Learning at level 2 and Docker at level 3. Python, SQL and AWS are mandatory; Machine Learning and Docker are optional but strongly recommended.

## A typical route from Software Developer

1. **Strengthen SQL first.** Most data engineering work is querying and modelling data. Moving from SQL level 2 to 4 is usually the biggest single step.
2. **Deepen Python** for data processing: working with files, APIs and data frames, and writing tested, reusable code.
3. **Learn the cloud foundations**, then the AWS services used for data workloads. Take the foundations course before the intermediate one.
4. **Package and deploy** with Docker so pipelines run the same way everywhere.
5. **Practise on a real project.** Ask your manager for a small data pipeline task in your current team.

## Tips

- Spread long courses over several weeks; 40 hours of learning time are available each year.
- After each course, ask for a skill re-assessment so your learning path stays accurate.
- Use the learning path in the LMS: it orders the courses so prerequisites come first.
