# app/ml – machine learning engine

**Filled in:** Phase 8 (models) and Phase 16 (MLflow retraining).

| Planned file | Purpose |
| --- | --- |
| `features.py` | Turns employee/course data into model inputs |
| `train.py` | Trains Logistic Regression / Random Forest pipelines |
| `evaluate.py` | Metrics and comparison with the current model |
| `predict.py` | Loads the approved model and predicts completion likelihood |
| `model_registry.py` | MLflow registration, promotion and rollback |

Synthetic labels are used for demonstration only and are labelled as such.
